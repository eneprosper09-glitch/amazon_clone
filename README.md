# 🛒 Amazon Clone

A responsive Amazon-inspired e-commerce website built with **HTML, CSS, and JavaScript**.

This project was created as a web development practice project to recreate the structure and functionality of an online shopping platform.

## 📌 Project Overview

This Amazon Clone includes a homepage, navigation system, product categories, individual category pages, product cards, search functionality, wishlist, shopping cart, and other e-commerce-style pages.

The project focuses on practicing:

- HTML structure
- CSS styling and responsive layouts
- JavaScript functionality
- Navigation between pages
- Product organization
- Search functionality
- Shopping cart functionality
- Wishlist functionality
- Git and GitHub

Features

 🏠 Homepage

The homepage includes:

- Amazon-inspired navigation bar
- Logo
- Delivery location
- Search bar
- Account & Lists
- Returns & Orders
- Wishlist
- Shopping Cart
- Secondary navigation menu
- Hero image slider
- Product categories
- Product cards
- Best Sellers section
- Footer

---

🔎 Search

The search bar allows users to search for products across the website.

Users can search for products such as:

- Headphones
- Power Bank
- Samsung S24 Ultra
- Gaming Mouse
- Sweater
- Kitchen products
- Beauty products

The search functionality is designed to take the user to the relevant product/category.
